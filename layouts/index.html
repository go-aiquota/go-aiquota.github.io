go-aiquota is a cross-platform menu-bar app that watches AI usage quotas — session and weekly limits — across multiple accounts at once (Claude Max, Claude Team Premium, Claude Team Standard today). Each provider is a separate subprocess plugin talking a small hashicorp/go-plugin gRPC contract (go-aiquota/proto), so adding a provider is writing a plugin, not forking the host. Onboarding an account drives a real, isolated embedded browser straight to the provider's own login page — no manual cookie copying, no devtools.

Adding a provider

Implement the QuotaProvider contract and serve it as a go-plugin subprocess:

func (p *myProvider) Describe(...) (*quotapb.ProviderInfo, error) { ... }
func (p *myProvider) FetchQuota(...) (*quotapb.QuotaSnapshot, error) { ... }

hcplugin.Serve(&hcplugin.ServeConfig{
    HandshakeConfig: plugin.Handshake,
    Plugins:         plugin.Map(p),
})
